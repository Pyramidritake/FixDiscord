> [!WARNING]

> ### АНТИВИРУСЫ
>
> Для работы zapret необходим WinDivert, поэтому антивирус может отреагировать на него.  
> WinDivert перехватывает и фильтрует сетевой трафик. Сам по себе он не является вирусом, хотя такой инструмент могут применять как легитимные, так и вредоносные программы.
>
> **Фрагмент [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) проекта [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)**
>
> Некоторые антивирусы относят WinDivert к инструментам повышенного риска или хакерским средствам, после чего удаляют файл и помещают его в карантин. Название такого обнаружения обычно содержит `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`.
>
> Добавьте каталог zapret в исключения антивируса либо отключите обнаружение PUA, то есть потенциально нежелательных приложений. Например, Kaspersky предлагает настройку "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Исключение предпочтительно при корректной настройке, но если вы не уверены в своих действиях, отключите обнаружение PUA.

## ⚙️ Использование

1. Сначала включите безопасный DNS (Secure DNS).
   * В Chrome активируйте "Использовать безопасный DNS" и выберите поставщика, отличного от "Поставщик по умолчанию".
   * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", выберите "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован.
   * Windows 11 позволяет включить Secure DNS в настройках самой ОС. [Инструкция находится здесь](https://remontka.pro/dns-over-https-windows-11/); для Windows 11 этот вариант рекомендуется.
   * Владельцам роутеров Keenetic нужно включить в настройках параметр "Транзит запросов". При выключенной опции Secure DNS на компьютере может работать некорректно.

2. Загрузите zip- или rar-архив с [последнего релиза](https://github.com/Pyramidritake/zapret-discord-youtube/releases/latest).

3. Откройте свойства архива и включите параметр "Разблокировать". Пользователям 7-Zip и PeaZip этот шаг выполнять не обязательно.

4. Распакуйте архив в каталог, путь к которому не содержит кириллицу и специальные символы.

5. Запустите нужный скрипт:
   * Для поиска рабочей стратегии откройте **`service.bat`** и выберите `Run Tests` -> `Standard tests` -> `All configs`.
   * Чтобы добавить выбранную стратегию в автозапуск, перейдите в **`service.bat`**: `Install Service` -> *выберите подходящую стратегию*.

## ℹ️ Назначение файлов

- [**`general.bat ...`**](./general.bat) запускает стратегию вручную.

  Такой запуск удобен для проверки конфигураций. Результат зависит от множества условий, поэтому перебирайте разные варианты, включая **ALT**, **FAKE** и другие, пока не найдёте подходящий для себя.

- [**`service.bat`**](./service.bat) содержит установку автозапуска и дополнительные операции:
  - <ins>**`Install Service`** добавляет выбранную стратегию в службы Windows (services.msc).</ins>
  - **`Remove Services`** удаляет стратегию и WinDivert из служб.
  - **`Check Status`** показывает состояние обхода и служб, включая автозапущенную стратегию и WinDivert.
  - **`Game Filter`** меняет режим обработки игр и других сервисов, использующих UDP и TCP-порты выше 1023.  
  **После изменения этого режима стратегию нужно перезапустить.**  
  Значение в скобках показывает текущий статус: включено или выключено.
  - **`IPSet Filter`** управляет фильтрацией сервисов из `ipset-all.txt`. Это полезно при проверке ресурса, который без zapret работает, а с ним перестаёт открываться.  
  В скобках отображается состояние:
    - `none` - ни один IP не проходит проверку
    - `loaded` - IP сверяется со списком
    - `any` - под фильтр попадает любой IP  
  - **`Auto-Update Check`** включает или отключает автоматический поиск обновлений.
  - **`Replace active fakes`** меняет текущий фейк на другой файл из каталога `bin`.
  - **`Update IPSet List`** заменяет `ipset-all.txt` актуальной версией из репозитория.
  - **`Update Hosts File`** обновляет hosts <ins>для восстановления веб-версии Telegram и подключения к голосовому чату Discord.</ins>
  - **`Check for Updates`** вручную проверяет наличие обновлений.
  - **`Run Diagnostics`** ищет распространённые причины неисправности zapret.  
  В завершение можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает после внезапной остановки работы клиента.
  - **`Run Tests`** проверяет стратегии:
    - `Standard tests` проверяет сайты из `utils/targets.txt`.
    - `DPI checkers` проверяет DPI у разных провайдеров, включая Cloudflare и Amazon.

## ☑️ Частые вопросы и неполадки

### После запуска `general*` ничего не видно

При запуске стратегии отдельным bat-файлом, а не через service, в панели задач должен появиться `winws.exe`, отвечающий за обход.  
Если процесс не появился, обратитесь к [#522](https://github.com/Pyramidritake/zapret-discord-youtube/issues/522).

### Не нашлось подходящей стратегии

Откройте командную строку с правами администратора и выполните команды по очереди:

`netsh winsock reset`

`netsh int ip reset all`

`netsh winhttp reset proxy`

`ipconfig /flushdns`

Затем перезагрузите компьютер.

### Веб-версия Telegram не подключается

В **`service.bat`** выберите **`Update hosts file`**. Если установленный hosts устарел, программа предложит обновить его вручную:

- скопируйте весь текст из открытого блокнота;
- от имени администратора откройте текстовым редактором файл `hosts` в появившемся каталоге;
- вставьте скопированные строки в конец файла или замените ранее добавленные аналогичные записи;
- сохраните файл и проверьте соединение ещё раз. Если проблема останется, убедитесь, что изменения действительно сохранились.

#### Работоспособность не гарантируется. При неудаче используйте [Telegram Desktop](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/Pyramidritake/tg-ws-proxy) или любым публичным прокси.

### Обход не запускается или перестал работать

> [!IMPORTANT]
> **Стратегии не обязательно работают постоянно.**
> После обнаружения определённая стратегия может перестать работать, даже если раньше она помогала. В репозитории есть много вариантов обхода. Если готовые конфигурации не подходят, создайте новую на основе одной из них и измените параметры.
> Описание параметров доступно [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Проверьте сообщения в `service.bat` -> `Run Diagnostics`.
- Убедитесь, что нужный адрес присутствует в списках доменов или IP.
- Испытайте другие варианты, включая **`ALT`** и **`FAKE`**.
- Выполните полную переустановку по инструкции ниже.
- Дополнительная информация есть в [#765](https://github.com/Pyramidritake/zapret-discord-youtube/issues/765).

### Как полностью обновить или переустановить проект?

- Сохраните добавленные вами ресурсы и данные.
- Перезагрузите устройство.
- Выполните `service.bat` -> `Remove Services`.
- Запустите `service.bat` -> `Run Diagnostics`; устраните найденные ошибки и в конце ответьте `Y`.
- Удалите каталог zapret.
- Скачайте последнюю сборку (`zapret-discord-youtube-...`) со [страницы релизов](https://github.com/Pyramidritake/zapret-discord-youtube/releases).
- Откройте свойства архива через контекстное меню. Если внизу есть пункт разблокировки, отметьте его, нажмите "Применить", затем "ОК".
- Распакуйте архив в новый каталог в корне диска, без пробелов, специальных символов и кириллицы.
- Запускайте разные `general`-скрипты и проверяйте ресурсы. Если интернет не работает, закройте программу через значок замка в панели задач и попробуйте следующую стратегию.
- Найдя рабочий вариант, добавьте его в автозапуск через `service.bat` -> `Install Service`.

### Игра или приложение не работает при включённом zapret

В `service.bat` проверьте, что `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` - **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит сообщает о WinDivert

Инструкция доступна в репозитории https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide.

### Windows 7 требует цифровую подпись драйвера WinDivert

Замените `WinDivert.dll` и `WinDivert64.sys` в [`bin`](./bin) одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### После удаления через [**`service.bat`**](./service.bat) WinDivert остался в службах

1. Найдите имя службы в командной строке Windows, открытой через Win+R -> `cmd`:

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8F-использование).
- Отключите блокировщик рекламы: известно, что YouTube начал активно с ними бороться.
- Переберите остальные стратегии, особенно если прежняя конфигурация недавно перестала работать.
- Дополнительные сведения: [#251](https://github.com/Pyramidritake/zapret-discord-youtube/discussions/251).

### Не запускается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что включён [Secure DNS](#%EF%B8%8F-использование).
- Определите стратегию, на которой открывается YouTube, и запустите её.
- Через `service.bat` -> `Run Diagnostics` очистите кэш Discord.
- Проверьте, помогла ли очистка кэша приложению Discord.
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, временно пользуйтесь ей.
- Если сайт также недоступен, повторно проверьте все стратегии: YouTube и Discord могут работать на разных конфигурациях.
- См. также [#252](https://github.com/Pyramidritake/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/Pyramidritake/tg-ws-proxy).
- Либо подключите бесплатный MTProto-прокси из интернета.

### Не запускаются игры

Игр много, поэтому проверить и исправить каждую из них невозможно.

Начните с универсальной последовательности:

- обновите ipset через `service.bat` и включите `Game Filter`;
- если результата нет, дополнительно включите `ipset any`.

У `ipset any` есть побочный эффект: многие сайты могут перестать открываться. Не оставляйте этот режим включённым постоянно. Вместо этого определите IP-адреса, которые использует игра, и внесите их в `ipset-all.txt`.

Если проблема не решилась, создайте обсуждение в разделе [Discussions](https://github.com/Pyramidritake/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Проблемы нет в списке

Опишите её [в разделе issues](https://github.com/Pyramidritake/zapret-discord-youtube/issues).

## 🗒️ Добавление адресов других ресурсов

Расширить список обхода можно через следующие файлы:

- **`list-general-user.txt`** - домены; поддомены учитываются автоматически;
- **`list-exclude-user.txt`** - домены, которые нужно исключить, например когда сеть уже есть в `ipset-all.txt`, но конкретный домен фильтровать не следует;
- **`ipset-all.txt`** - IP-адреса и подсети;
- **`ipset-exclude-user.txt`** - IP-адреса и подсети, подлежащие исключению.
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`.
